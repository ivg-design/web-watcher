# v3 build spec (workers). Read .reviews/v3-concept.md first, then your section here.

## Rules for every worker
- Strict file ownership (your section). Never edit other files; report needs in your final message.
- A previous worker may have left partial work in your files (session was interrupted). Read what is there, keep what matches the spec, finish the rest.
- Tree must compile at all times: `npx tsc --noEmit -p .` and `npm run lint` clean before you finish.
- Verify against http://localhost:3101 READ-ONLY (the owner's dev server, HMR). Never start, stop or restart any server; never run `next dev` or `next build`. If 3101 is down or shows a compile error from a file you do not own, wait 20 s and retry; if still down, finish by typecheck/lint and say so.
- puppeteer-core headless only (`tests/_h.mjs` pattern, `BASE=http://localhost:3101 node tests/<name>.mjs`); always `browser.close()` in a finally; never kill Chrome; never open windows or activate apps.
- Screenshots to `/private/tmp/claude-501/-Users-ivg-github-web-watcher/1b5c3420-5ad4-4c49-88f4-04aad1e374ed/scratchpad/<worker>/`; LOOK at them (Read tool) at 1440x900 and 390x844 in every interactive state before reporting. No horizontal overflow at 390.
- Tokens and primitives in `src/app/globals.css`: `.night`, `.paper`, `--n-*`, `--p-*`, `.t-cond`, `.t-wide`, `.t-num`, `.t-label`, `.h2-v3`, `.roll`. `asset()` from `@/lib/config` for root-relative URLs. `data-testid` on every interactive piece.
- Motion verb is TICK: numbers roll one step (`.roll`, or `src/components/landing/hero/Roll.tsx` if present), colours cut with no transition, entrances are hard cuts, nothing fades, scales or bounces, no scroll-reveal, no hover-scale. Transform/opacity only, `--ease-expo`. Reduced motion renders end states (swaps, no loops).
- Copy: no em dashes (except inside real macOS/Safari strings), no middle-dot chains in new copy, no emojis, no eyebrows, no section numbering. Proper nouns in `<span className="nw">` (WebWatcher, Apple Silicon, macOS 13, Developer ID, IVG Design, GitHub). Buttons never wrap.
- Mocks keep the app's REAL strings (see .reviews/round2-audit.md). No `speechSynthesis`; Kokoro samples click-only.
- Touch targets >= 44 px at `(pointer: coarse)`. `aria-live` only on user-initiated outcomes.
- Do not commit. Final message: what you built or changed, what each interactive element demonstrates, test output, screenshot paths, needs from the lead.
